# Contributing to Forge AI

Thanks for helping! Forge AI is small on purpose: plain Python, standard library only, everything runs locally.

## Setup
1. Python 3.9+ and [Ollama](https://ollama.com) with the two models listed in the README.
2. Run the tests (no Ollama needed): `python3 -m unittest discover -s tests`

## Good first steps
- Look for issues labeled **good first issue**.
- Ask in [Discussions](https://github.com/milesgurule-png/forge-ai/discussions) before starting something big.

## Rules
- No new dependencies without a discussion first.
- Nothing may send notes or questions off the machine.
- Add or update a test for any behavior change, and keep `python3 -m unittest` green.
